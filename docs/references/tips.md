# Referências

Esta página reúne materiais recomendados para aprofundar os estudos da linguagem C, desde o nível iniciante até tópicos avançados.

---

# Livros

## Iniciante

### The C Programming Language (K&R)

**Autores:** Brian W. Kernighan e Dennis M. Ritchie

O livro clássico escrito pelo criador da linguagem C e seu coautor. É considerado a principal referência para compreender os fundamentos da linguagem.

**Indicado para:**
- Sintaxe
- Boas práticas
- Conceitos fundamentais

---

### C Programming: A Modern Approach

**Autor:** K. N. King

Excelente para iniciantes. Explica conceitos de forma gradual e possui centenas de exercícios.

**Indicado para:**
- Aprendizado estruturado
- Exercícios
- Linguagem moderna

---

## Intermediário

### Expert C Programming: Deep C Secrets

**Autor:** Peter van der Linden

Explora detalhes internos da linguagem, compiladores e armadilhas comuns.

---

### C Traps and Pitfalls

**Autor:** Andrew Koenig

Livro clássico sobre erros frequentes cometidos por programadores C.

---

### Modern C

**Autor:** Jens Gustedt

Aborda o padrão C11/C17 com foco em programação moderna.

---

## Avançado

### Understanding and Using C Pointers

**Autor:** Richard Reese

Livro dedicado ao estudo de ponteiros e gerenciamento de memória.

---

### 21st Century C

**Autor:** Ben Klemens

Mostra como escrever código C moderno utilizando bibliotecas atuais.
