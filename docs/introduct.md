# Introdução à Linguagem C

## O que é C?

A linguagem C é uma linguagem de programação de propósito geral, compilada, estruturada e de alto desempenho. Foi desenvolvida por Dennis Ritchie em 1972 nos Bell Labs para o desenvolvimento do sistema operacional Unix.

Até hoje, C continua sendo uma das linguagens mais influentes da computação, servindo de base para linguagens como C++, Objective-C, Java, C#, JavaScript, Go e Rust.

---

## Principais Características

- Compilada
- Portável
- Eficiente
- Controle direto da memória
- Próxima do hardware
- Ampla utilização em sistemas operacionais, embarcados e software de alto desempenho

---

## Onde C é utilizada?

- Sistemas Operacionais
- Compiladores
- Drivers
- Sistemas Embarcados
- Microcontroladores
- Banco de Dados
- Game Engines
- Redes
- Computação de Alto Desempenho
