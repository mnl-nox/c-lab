# Exercícios — Básicos (01-basics)

Esta pasta reúne exercícios introdutórios sobre conceitos básicos da linguagem C.

Arquivos:

- `01-dataTypes.c` — Declaração e impressão de variáveis de tipos primitivos.
- `02_dataTypesManipulation.c` — Operações e manipulação entre tipos (soma, produto, strings).
- `03-stringManipulation.c` — Manipulação básica de strings e uso de `<string.h>`.
- `04-stringArrays.c` — Exemplos com arrays de caracteres e contagem de caracteres.
- `05-input-output.c` — Entrada e saída via terminal (ex.: `scanf`, `printf`).
- `06-operations.c` — Operadores aritméticos e exemplos práticos.

Como compilar e executar (Linux/macOS):

```bash
gcc 01-dataTypes.c -o 01-dataTypes
./01-dataTypes

gcc 02_dataTypesManipulation.c -o 02-dataTypesManipulation
./02-dataTypesManipulation

gcc 03-stringManipulation.c -o 03-stringManipulation
./03-stringManipulation

gcc 04-stringArrays.c -o 04-stringArrays
./04-stringArrays

gcc 05-input-output.c -o 05-input-output
./05-input-output

gcc 06-operations.c -o 06-operations
./06-operations
```
