# Exercícios — Controle de Fluxo (02-control-flow)

Esta pasta reúne exercícios sobre estruturas de controle em C: condicionais e laços.

Arquivos:

- `01-ifElse.c` — Exercício sobre `if` / `else`.
- `02-while.c` — Exercício sobre `while` (laços).
- `03-for.c` — Exercício sobre `for`.
- `04-doWhile.c` — Exercício sobre `do`/`while`.
- `05-switch.c` — Exercício sobre `switch`.

Como compilar e executar:

```bash
gcc 01-ifElse.c -o 01-ifElse
./01-ifElse

gcc 02-while.c -o 02-while
./02-while

gcc 03-for.c -o 03-for
./03-for

gcc 04-doWhile.c -o 04-doWhile
./04-doWhile

gcc 05-switch.c -o 05-switch
./05-switch
```

Notas:

- Nível recomendado: Iniciante → Intermediário.
